# web-report-publish

用來公開分享各種分析報告的靜態網站。每份報告都是一個獨立的 HTML 檔，資料與圖表都包在檔案裡，不需要後端，瀏覽器打開就能看。

主題不限，目前收錄的是 Path of Exile 的市場分析。

## 線上瀏覽

透過 GitHub Pages 發布：<https://kilbc634.github.io/web-report-publish/>

需要先在 repo 的 Settings → Pages 把來源設為 `main` 分支的根目錄，網址才會生效。

## 目錄結構

```
index.html      報告總目錄（首頁）
reports/        每份報告一個 HTML 檔
```

## 新增報告

1. 把報告的 HTML 檔放進 `reports/`。檔案要能獨立開啟，不要引用本機路徑。
2. 在 `index.html` 的清單最上面複製一個 `<li>` 區塊，改掉連結、標題、說明與日期。
3. 在上面的「目前的報告」表格加一列。
4. 發布前確認檔案裡沒有帳號、金鑰、私人網址等不該公開的內容。

## 注意事項

- 報告是特定時間點的快照，不會自動更新；價格類的內容很快就會過時。
- 報告裡的估算（例如掉落率、時薪）都附有假設與資料來源，請搭配閱讀，不代表實際收益。
- 引用的第三方資料歸原作者所有，來源列在各報告內。
